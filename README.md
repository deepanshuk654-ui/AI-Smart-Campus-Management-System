AI Smart Campus Management System
Overview

AI Smart Campus Management System is a Flask-based web application that helps educational institutions manage campus communication and student grievances efficiently. The system includes a Digital Notice Board, Complaint Management System, and AI-powered complaint categorization.

Features

User Registration & Login
Digital Notice Board
Complaint Management System
AI-Based Complaint Categorization
Complaint Status Tracking
Admin Dashboard
Role-Based Access Control

Technologies Used

Python
Flask
SQLite
HTML
CSS
JavaScript
Bootstrap

Objectives

Improve campus communication.
Simplify complaint handling.
Reduce manual paperwork.
Enhance student-administration interaction.
